# Map layer Format

## Format

```json
"newLayer" :
{
	// Human-readable name of the layer
	"text" : "My Layer",

	// Optional. Tavern rumor about region of this layer that contains the Grail
	// %s is replaced with name of the region, for example "northern". Layers without this text have no such rumor
	"grailRumor" : "The Grail may be found in the %s regions of my layer."
}
```
