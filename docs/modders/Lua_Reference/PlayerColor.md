# PlayerColor

Player colours, plus the neutral owner used by unowned objects.

| Key | Value | Description |
| --- | ----- | ----------- |
| `red` | 0 | Player red. |
| `blue` | 1 | Player blue. |
| `tan` | 2 | Player tan. |
| `green` | 3 | Player green. |
| `orange` | 4 | Player orange. |
| `purple` | 5 | Player purple. |
| `teal` | 6 | Player teal. |
| `pink` | 7 | Player pink. |
| `neutral` | -1 | No owner - used by unowned towns, mines and dwellings. |
