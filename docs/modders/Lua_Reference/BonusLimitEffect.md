# BonusLimitEffect

Kinds of combat a bonus is limited to, used by Bonus `effectRange`.

| Key | Value | Description |
| --- | ----- | ----------- |
| `noLimit` | 0 | Applies to every kind of combat. |
| `onlyDistanceFight` | 1 | Applies only while shooting. |
| `onlyMeleeFight` | 2 | Applies only in melee. |
