# PrimarySkill

The four primary hero skills.

| Key | Value | Description |
| --- | ----- | ----------- |
| `attack` | 0 | Attack skill, raises damage dealt by the hero's troops. |
| `defence` | 1 | Defence skill, lowers damage taken by the hero's troops. |
| `spellpower` | 2 | Spell power, scales the effect of the hero's spells. |
| `knowledge` | 3 | Knowledge, scales the hero's maximum spell points. |
