# Difficulty

Game difficulty levels, named after chess pieces (pawn = easiest, king = hardest).

| Key | Value | Description |
| --- | ----- | ----------- |
| `pawn` | 0 | Easy difficulty. (80%) |
| `knight` | 1 | Normal difficulty. (100%) |
| `rook` | 2 | Hard difficulty. (130%) |
| `queen` | 3 | Expert difficulty. (160%) |
| `king` | 4 | Impossible difficulty. (200%) |
